## Phase 1 — Channel and physical layer (`orbit.py`, `channel.py`)
1. Compute SNR from the **SGP4 slant range** and the actual satellite altitude, not a fixed 600 km [C-8].
2. Complete the link budget per TR 38.821 Table 6.1.1.1. Add polarisation loss (3 dB), atmospheric (0.1 dB), scintillation (2.2 dB at S-band), and shadow-fading margin (3 dB). Each one is a config value with a source [D-5].
3. **Per-device coupling loss:** meters get an extra loss drawn from an indoor/outdoor penetration and shadowing distribution. This creates real SNR diversity across meters and gives CE levels a purpose [D-7]. **[DECISION Q3]**
4. **Recalibrate P_d(SNR, N_rep)** so that 1 − P_d passes through the chosen published points, using a least-squares logistic fit. Report the fit residual in a test, and write the fitted values into the paper's parameter table [C-1, D-4, I-2]. **[DECISION Q2]**
5. Replace the inactive "residual Doppler 10/250 Hz" stress axis with an axis that changes detection [D-2]. **[DECISION Q2]**

## Phase 2 — NB-IoT access model (`nprach.py`)
1. **CE levels.** Each meter picks CE0/1/2 from its RSRP against thresholds. Each CE level has its own subcarrier pool (for example 24/12/12 of the 48) and its own repetition count [D-3, D-7].
2. **Barring.** Interpret p as "fraction of the 10 access classes allowed by the NB-IoT AB bitmap" (so p ∈ {0.1 … 1.0}). Apply the check **only at RA initiation**, not on preamble retransmissions [L-7, C-10].
3. **Collision semantics.** Colliding meters on one subcarrier all fail at Msg4 (no capture effect, stated as an assumption). The gNB sees collided subcarriers through an early-collision-detector model with detection probability P_cd [18], [19] [L-6].
4. **Timeout** **[DECISION Q1]**.
5. **Delay** = arrival → Msg4. It includes the barring wait, backoffs, preamble airtime N_rep × 5.6 ms, RTT, and RAR/Msg3/Msg4 processing [C-9].
6. **Traffic** that doesn't depend on the pass: periodic AMI reports as uniform/Poisson arrivals over the whole pass, plus one Beta(3,4) synchronised "alarm-storm" burst (TR 37.868 model 2) at a **random** time. This removes the hard-coded multiphase times [C-4].
7. **Energy metric** = preamble airtime per successful meter, Σ N_rep × T_pre [D-13].

## Phase 3 — MDP and reward (`mdp.py`, `agent.py`)
1. **Observable state** [C-7]:
   - load is estimated from the previous RAO's idle and collided subcarrier counts (standard Poisson inversion);
   - elevation bin from ephemeris;
   - pass-phase bin;
   - the Doppler bin is dropped, or replaced by the new stress indicator if Q2 adds one.
2. **Observable, cause-separated reward** [C-3, D-6]:
   - successes and collided subcarriers come from the gNB's own detections;
   - misses are estimated from the expected vs detected load;
   - normalisation is per *preamble resource*, not per transmission, plus a backlog-age penalty so over-barring is no longer rewarded;
   - the timeout term follows Q1.
3. The ablation has the same agent and state, with one lumped penalty. Its pre-training uses its **own** reward [D-12].
4. Small agent fixes: honour `eps0` for warm start, add the terminal update at the end of a pass, and skip Q-updates on idle RAOs [C-13, C-14].

## Phase 4 — Baselines (`baselines.py`)
| ID | New definition |
|---|---|
| B1 | Fixed terrestrial-style configuration (p = 1, BI = 256 ms, CE reps {1, 2, 4}), with an NTN-correct RAR window. No strawman timeouts. |
| B2 | "Static NTN-aware configuration". Renamed from "Rel-17 default", with each value justified [D-8]. |
| B3 | Terrestrial-frozen Q. Trained on a **real terrestrial channel** (high SNR, ~0 delay), with a load-only state, then deployed unmodified [D-10, C-5]. |
| B4 | Hand-written channel-aware heuristic. Same rules, using **observable** inputs only. |
| B5 | **Best fixed configuration (genie).** Exhaustive search over all 60 actions on the test passes. This is the honest "best static" reference [D-9]. |
| Abl | Lumped-reward Q-learning. |
| Warm | Pre-trained on **other passes** (different days or satellites from the TLE file), never on a test pass. The training budget is reported [D-11, C-6]. |
| Cold | Zero-initialised, learned inside one pass. This is the true "converges within a pass" test. |

## Phase 5 — Experiments (`experiment.py`)
1. **Geometry diversity** [C-12]:
   - Test set: every pass with peak elevation ≥ 20° over 7 days, for SATELIOT_2.
   - Training set for warm start: passes from SATELIOT_1/3/4 (no overlap with the test set).
2. Each test pass gets 10 traffic seeds. Report mean ± 95 % CI. Run a paired Wilcoxon signed-rank test of Proposed vs B2, B5, and the ablation [C-11].
3. **Sweeps** [I-5]:
   - device count N ∈ {200, 1000, 3000, 5000};
   - the Q2 stress axis;
   - RAO period ∈ {160, 320, 640} ms;
   - altitude ∈ {500, 600, 800} km, using synthetic circular-orbit TLEs at the same inclination (assumption A-9).
4. Outputs: `metrics.csv` and per-attempt `attempts.parquet`. Each run writes a manifest with the config hash, seeds, package versions, and TLE epochs.
